Open your terminal and run: npm create vite@latest my-ai-ui -- --template react

Move into the directory: cd my-ai-ui

Install dependencies: npm install

Install Tailwind CSS: npm install -D tailwindcss postcss autoprefixer and then npx tailwindcss init -p (follow the quick setup on Tailwind's website to configure your tailwind.config.js).

Paste the code above into src/App.jsx.

Run your frontend: npm run dev.
